# Release Self-Check

Release: `v0.1.0`

The package was generated with a safety-first static review. The repository intentionally contains no production credentials, no customer data, no executable GitHub Actions workflow, no remote-install command, and no autonomous regulatory-decision logic.

## Checks performed

- [x] No plaintext API keys, tokens, passwords, private keys, or credentials intentionally included.
- [x] No customer / patient / employee confidential data intentionally included.
- [x] No shell installer, remote code execution, pipe-to-shell installer, destructive filesystem command, or hidden executable payload intentionally included.
- [x] External regulatory links limited to recognized official-government / authority domains in the source registries.
- [x] Prompts explicitly treat retrieved material as untrusted data.
- [x] Prompts prohibit fabricated regulations, article numbers, dates, and enforcement status.
- [x] Prompts require evidence and current-status checks.
- [x] Binding requirements are separated conceptually from guidance, Q&A, enforcement correspondence, draft, and historical material.
- [x] Human review is required for regulated or high-impact decisions.
- [x] Repository does not claim that AI output constitutes legal or regulatory advice.
- [x] No proprietary Aves AI Hub runtime, customer configuration, credential, commercial workflow, or private knowledge base content is included.

## Known limitations

- This is an initial taxonomy/retrieval framework, not a complete regulatory database.
- Regulatory sites change over time; links and status must be revalidated.
- Terminology mappings are intentionally conservative and will require community refinement.
- EU medicines regulation is not synonymous with EMA alone; European Commission / EudraLex and other network authorities may be authoritative for particular topics.
- FDA Warning Letters and Form FDA 483 observations are enforcement/inspection evidence, not themselves generally applicable binding regulations.
- NMPA notices, announcements, technical guidelines, and formal regulations must be distinguished by document type and legal effect.

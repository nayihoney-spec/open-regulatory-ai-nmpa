# Support the project

The framework is intended to remain freely usable and community-reviewable.

If the project saves you research time or helps improve regulatory AI quality, you can support ongoing maintenance through GitHub Sponsors for **@nayihoney-spec** once the sponsored developer profile is active.

Repository funding configuration is included in `.github/FUNDING.yml`.

You can also support the project without money by:
- reporting missing or outdated regulations;
- submitting corrected mappings;
- contributing multilingual synonyms;
- sharing anonymized retrieval failure cases;
- reviewing pull requests.

> Note: the GitHub Sponsor button only becomes functional after the maintainer completes GitHub Sponsors onboarding and approval. No payment credentials are stored in this repository.
